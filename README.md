# Yu-Gi-Oh MDCoinWatch

大师决斗的运势浮窗。后台看屏幕，记录每局的**投币胜负**、**实际先后手**和**对局胜负**，再给一句今日运势。

纯读屏幕像素：不注入、不改内存、不读游戏进程、不联网。

![浮窗](docs/widget.png)

**A tiny always-on-top overlay for Yu-Gi-Oh! Master Duel** — records, duel by duel, the coin toss, who actually goes first, and who won, plus a daily luck line. Screen-reading only. Chinese UI.

## 特色

**今日运势会说骚话。** 文案按「硬币正反 × 胜率」两个维度分档，还有 13 颗彩蛋。举几个例子：

| 触发的局面 | 它会说 |
| --- | --- |
| 硬币连输 5 次，但一局没输 | 我命由我不由天 |
| 硬币连赢 10 次 | 这就是鸿运齐天蛊的感觉吗 |
| 硬币很顺，胜率却很低 | 手气这么好还能输，绝了 |
| 硬币很顺，胜率一般 | 手气不错，可惜技术一般 |
| 硬币很背，胜率却很高 | 后手打成这样，你有点东西 |
| 今天正好打到 10 局 | 10 局，你是真要上分啊 |

全部 189 条在 [运势文案候选.md](运势文案候选.md)。

**不打扰游戏。** 无边框浮窗，点它、拖它、缩放它都不抢游戏焦点。可以锁定位置防误碰，也能调透明度，直接压在游戏画面上。

**能进 OBS。** 右键打开「显示在任务栏」，OBS 的「窗口采集」就能抓到这个浮窗（采集方式选「Windows 10 (1903 and newer)」）。

## 用法

1. 游戏用 **16:9** 分辨率、**窗口或无边框窗口**运行
2. 双击 exe，浮窗出现在屏幕右上角
3. 切回游戏正常打，浮窗实时更新

**拖动**：拉边缘缩放，拉中间移动。

**右键浮窗**：

- 文字颜色 / 强调色 / 不透明度
- **显示在任务栏**（给 OBS 用）
- **累计硬币正面率**（显示在菜单里，不可点）
- 锁定位置与大小
- 打开记录文件 / 打开配置与日志
- **清除所有记录数据**（有二次确认）

## 浮窗显示什么

| 位置 | 含义 |
| --- | --- |
| 左上 金币 + 次数 + 百分比 | 今天投币猜赢的次数和比例 |
| 右上 黑币 + 次数 + 百分比 | 反面（被对手选走）的次数和比例 |
| 第二行 左 先/后 | 今天先攻、后攻的局数 |
| 第二行 右 胜/负 | 今天赢、输的局数 |
| 第三行 今日运势 | 按硬币和胜率分档的文案，带彩蛋 |
| 右上小圆点 | 绿 = 已锁定游戏，黄 = 对局中，灰 = 等游戏 |

第二行两组配色对应：斜杠左边的字和数字一个颜色，右边另一个颜色。

## 记录了什么

每局一行，开局就写、打完补时长和胜负：

```csv
time,coin,turn_order,duel_seconds,result,note
2026-10-03 21:10:00,WIN,FIRST,143,WIN,结束画面出现
```

| 列 | 含义 |
| --- | --- |
| `coin` | 投币胜负。`WIN` = 猜赢了自己选先后手，`LOSE` = 被对手选走 |
| `turn_order` | 实际先攻还是后攻 |
| `duel_seconds` | 对局时长 |
| `result` | 这局的胜负，看结束画面的金色皇冠在左还是右 |
| `note` | 收尾原因，出问题时看这个 |

浮窗上的「胜/负」只算**今天**；右键菜单里那行「累计硬币正面率」算的是**整份 CSV**（含前几天）。

## 注意事项

- 别用**独占全屏**，抓屏会拿到黑帧。窗口 / 无边框窗口没问题
- 分辨率用 **16:9**（1600x900 / 1920x1080 / 2560x1440 都行）
- 别把浮窗拖到屏幕**中下部那条横带**上，那是识别区，压住会暂停并提示
- 只在**游戏处于前台**时识别，切出去看数据会自动暂停
- exe **没有代码签名**，首次运行 SmartScreen 会拦：点「更多信息」→「仍要运行」
- **不联网**、不写注册表；CSV 不记对手、不记卡组、不记账号
- 日志里反复出现「没捕捉到横幅」，就把 ini 里的 `fps` 从 10 提到 20

## 数据

exe 旁边会生成三个文件，**建议单独放一个文件夹**：

- `duel_stats.csv` —— 每局一行
- `YuGiOh-MDCoinWatch.ini` —— 颜色、位置、大小、进程名、fps
- `YuGiOh-MDCoinWatch.log` —— 出问题看这个

## 原理

灰度模板匹配（TM_CCOEFF_NORMED），**先定屏再判内容**：投币以「先攻/后攻按钮在不在」为主判据，文字只做二次确认。窗口尺寸按 1920x1080 等比换算，三种分辨率实测命中 ≥ 0.968、误报 ≤ 0.366。

胜负看结束画面底部玩家信息栏上的**金色皇冠**：在左侧是自己赢，右侧是对方赢。结束画面是淡入的，所以会连采几帧取最大值再判。

## 开发

```
app/       C# / .NET 8，界面是纯 Win32 + GDI 自绘（无 WinForms，所以自带运行时能裁到 10.6 MB）
tools/     模板生成、硬币抠图、文案生成、一键发布
probe/     可行性分析脚本
build.ps1  构建，-Both 出两个版本
```

```powershell
.\build.ps1 -Both
.\dist\YuGiOh-MDCoinWatch.exe --selftest=你的截图目录   # 离线核对识别分数
.\dist\YuGiOh-MDCoinWatch.exe --replay=你的截图目录     # 跑一遍完整状态机
```

改运势文案：编辑 [运势文案候选.md](运势文案候选.md)，跑 `python tools/gen_fortune.py` 重新生成 `app/Fortune.cs`。

跑 `--selftest` 用的原始截图**没进仓库**（带玩家 ID），得自备。仓库里只有打码后的界面截图，在 [docs/screenshots](docs/screenshots)。
